# Spine Labels

Генератор етикеток для корінців папок. Один статичний сайт без бекенду й збірки: відкрийте `index.html` у браузері або розмістіть на GitHub Pages.

- список назв, по одній на рядок;
- лого (PNG/SVG), позиція, розмір і відступи;
- шрифт (Georgia, Cambria, PT Serif), авто-розмір під висоту з максимумом;
- колір тексту й тінь;
- розкладка на A4 у мм з лініями для різання, друк або «Зберегти як PDF».

Налаштування зберігаються в `localStorage` браузера.

## Друк

У діалозі друку: масштаб 100%, поля «Немає».

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.
